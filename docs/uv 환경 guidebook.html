uv가 뭔가요?

uv는 Python 개발에 필요한 모든 것을 하나로 합친 차세대 올인원 도구입니다. 기존에 pip, virtualenv, pyenv 등 여러 도구를 따로따로 배워야 했다면, 이제는 uv 하나만 알면 됩니다!

⚡

기존 pip보다 10~100배 빠른 속도

🧹

컴퓨터를 깨끗하게 유지

Python + 패키지를 한 번에

💾

🎓

초보자라면 이것만 기억하세요!

uv는 "Python 버전 관리 + 가상환경 + 패키지 설치"를 한 번에 해결해주는 마법 도구입니다. 예전처럼 여러 프로그램을 설치하고 복잡한 설정을 할 필요가 없어요!

비유로 이해하기

마치 도서관(창고)에서 책(Python)을 빌려서 내 책상(프로젝트)에서 읽는 것과 같아요. 책을 통째로 복사하지 않고, "이 책은 도서관 3번 서가에 있어요"라고 메모만 해두는 거죠!

uv 설치하기

설치는 정말 간단합니다! 운영체제에 맞는 명령어 한 줄이면 끝이에요.

Windows (권장 방법)

Windows에서는 winget을 사용하는 게 가장 편합니다.

PowerShell 
# uv 설치하기
winget install -e --id astral-sh.uv
다른 설치 방법 보기

Windows - PowerShell 스크립트

PowerShell 
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS / Linux

Bash 
curl -LsSf https://astral.sh/uv/install.sh | sh

설치 확인

터미널 
uv --version
💡

설치 후 터미널을 재시작하세요!

설치 직후에는 uv 명령어가 인식되지 않을 수 있어요. 터미널(PowerShell, 명령 프롬프트)을 껐다가 다시 열어주세요.

업데이트 & 삭제

PowerShell 
# 최신 버전으로 업데이트
winget upgrade astral-sh.uv

# 삭제하기
winget uninstall astral-sh.uv
🐍

Python 버전 관리하기

예전에는 Python을 설치하려면 공식 홈페이지에 가서 다운로드해야 했죠? 이제는 터미널에서 한 줄이면 됩니다!

Python 설치 (창고에 추가)

터미널 
# Python 3.12 버전을 창고에 설치
uv python install 3.12

# 여러 버전 설치도 가능!
uv python install 3.10
uv python install 3.11
📍

어디서 실행해도 괜찮아요!

uv python install은 어떤 폴더에서 실행하든 항상 같은 전용 창고에 설치됩니다. 설치된 Python은 제어판의 "프로그램 추가/제거"에 나타나지 않아요!

설치된 버전 확인

터미널 
uv python list

Python 삭제

터미널 
# 더 이상 필요 없는 버전 삭제
uv python uninstall 3.10
📁

새 프로젝트 시작하기

자, 이제 실제로 프로젝트를 만들어볼까요? 정말 쉬워요!

프로젝트 생성 (권장 방법)

터미널 
# 새 프로젝트 만들기 (Python 3.12 사용)
uv init my_project --python 3.12

# 프로젝트 폴더로 이동
cd my_project

이렇게 하면 my_project 폴더가 생기고, 그 안에 필요한 파일들이 자동으로 만들어집니다!

가상환경 직접 만들기 (선택사항)

보통은 자동으로 만들어지지만, 직접 만들고 싶다면:

터미널 
# 프로젝트 폴더 안에서 실행
uv venv --python 3.12
✨

자동 생성 기능!

uv add나 uv run 명령어를 실행할 때 .venv 폴더가 없으면 uv가 자동으로 만들어줍니다. 그래서 uv venv를 따로 안 해도 돼요!

Python 버전 바꾸기

프로젝트 중간에 Python 버전을 바꾸고 싶다면?

터미널 
# 기존 가상환경 삭제 (Windows)
rmdir /s /q .venv

# 새 버전으로 다시 만들기
uv venv --python 3.11
가상환경 활성화/비활성화 (고급)

uv run을 사용하면 활성화가 필요 없지만, 직접 python 명령어를 쓰고 싶다면:

PowerShell (Windows) 
# 활성화
.\.venv\Scripts\activate

# 비활성화
deactivate
Bash (macOS/Linux) 
# 활성화
source .venv/bin/activate

# 비활성화
deactivate
📦

패키지(라이브러리) 관리

pandas, numpy 같은 라이브러리를 설치해볼까요? pip install 대신 uv add를 사용합니다!

패키지 설치

터미널 
# 하나씩 설치
uv add pandas

# 여러 개 한 번에 설치
uv add pandas numpy matplotlib

# 특정 버전 설치
uv add pandas==2.1.0

패키지 삭제

터미널 
uv remove pandas
🗄️

패키지도 창고에서 빌려옵니다!

pandas를 처음 설치하면 uv가 전용 캐시 창고에 저장합니다. 다른 프로젝트에서 또 pandas를 설치해도 다시 다운로드하지 않고 창고에 있는 걸 링크해서 사용해요. 그래서 빠르고 용량도 절약됩니다!

캐시 정리하기

오래된 패키지들이 쌓이면:

터미널 
uv cache clean
🎯

실전 워크플로우

⚡ 새 프로젝트 시작하기 (3단계)

1

프로젝트 생성

uv init my_project --python 3.12
cd my_project
2

패키지 설치

uv add pandas numpy
3

코드 실행

uv run main.py

Python 파일 실행하기

터미널 
# 가상환경 활성화 없이 바로 실행!
uv run main.py

# 특정 스크립트 실행
uv run scripts/data_analysis.py

Jupyter Notebook 사용하기

터미널 
# 필수 패키지 설치
uv add ipykernel jupyter

# Jupyter Notebook 실행
uv run jupyter notebook

알아두면 좋은 팁

VS Code에서 설정하기

VS Code를 사용한다면 Python Interpreter를 올바르게 선택해야 합니다:

  1. Ctrl + Shift + P (Mac: Cmd + Shift + P)를 눌러 명령 팔레트 열기
  2. "Python: Select Interpreter" 검색
  3. ('.venv': uv)라고 표시된 항목 선택
  4. 목록에 없다면 .venv/Scripts/python.exe를 직접 지정
⚠️

"아무데서나 python이 실행 안 돼요!"

정상입니다! uv는 시스템을 깨끗하게 유지하기 위해 전역 python 명령어를 등록하지 않아요. 프로젝트 폴더에서 uv run을 사용하거나, 가상환경을 활성화하세요.

프로젝트 삭제는 간단하게!

🗑️

그냥 폴더를 삭제하면 됩니다!

프로젝트가 끝나면 프로젝트 폴더 전체를 휴지통에 버리세요. 예전처럼 "프로그램 추가/제거"에서 지울 필요 없어요. 시스템에 찌꺼기가 남지 않습니다!

서로 다른 프로젝트, 서로 다른 환경

A 프로젝트는 Python 3.12 + pandas 2.0, B 프로젝트는 Python 3.10 + pandas 1.5를 써도 전혀 문제없어요. 각 프로젝트의 .venv가 완전히 독립되어 있으니까요!

부록: 기존 환경 정리하기

uv로 완전히 전환하기 전에 기존에 설치된 Conda나 전역 Python을 정리하면 더 깔끔합니다. 꼭 필요한 건 아니지만, 권장드려요!

🐍 Conda 완전 삭제하기 (Windows)

프로그램 제거

설정 → 앱 → 앱 및 기능에서 Miniconda 또는 Anaconda를 찾아 제거합니다.

잔여 폴더 삭제

탐색기에서 아래 폴더들을 수동으로 삭제하세요:

  • C:\Users\사용자명\.conda
  • C:\Users\사용자명\.condarc
  • C:\Users\사용자명\miniconda3 (또는 anaconda3)

환경 변수 정리

Windows 검색에서 "시스템 환경 변수 편집" 검색 → 환경 변수 → Path에서 Conda 관련 경로 삭제

🐍 전역 Python 완전 삭제하기 (Windows)

프로그램 제거

설정 → 앱 → 앱 및 기능에서 Python 3.x 및 Python Launcher를 찾아 제거합니다.

잔여 폴더 삭제

탐색기 주소창에 아래 경로를 붙여넣고 폴더가 있으면 삭제:

  • %LocalAppData%\Programs\Python
  • %AppData%\Python

환경 변수 정리

"시스템 환경 변수 편집" → Path에서 Python, Python\Scripts 경로 삭제

Windows 앱 별칭 비활성화

Windows 검색에서 "앱 실행 별칭 관리" 검색 → Python 관련 항목 모두 끔으로 설정

✅

삭제 확인 방법

PowerShell에서 python --version 입력 후 "명령어를 찾을 수 없음" 메시지가 나오면 성공!
